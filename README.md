# Neural Network From Scratch

A neural network built from scratch using Python and NumPy to understand the mathematics and algorithms behind neural networks.

## Project Goals

- Understand how neural networks work internally
- Implement forward propagation
- Implement backpropagation
- Implement gradient descent
- Build reusable neural network layers
- Train the network on real datasets
- Compare the final implementation with PyTorch

## Technologies

- Python
- NumPy
